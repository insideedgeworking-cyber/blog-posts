# 執筆ルール（たたき台）

参考3ブログ（ヒトデブログ／副業コンパス／きつねコード）の成功記事を分析して抽出した「勝ちパターン」を、
自分が記事を書くときのチェックリスト・ルールにまとめたもの。※丸写しはせず、型と考え方だけ採用する。

> このファイルはアプリの本文生成・修正時に自動で読み込まれる。気づいた改善はここに追記していく。

---

## 0. 大前提（3ブログ共通の勝ち筋）
- **「情報提供のフリをした意思決定支援」**。読者が「で、結局どうすればいい？」に最後まで答える。
- **結論を先に出す**。もったいぶらない。読者の時間を尊重する。
- **実体験と数字で信頼を作る**。一般論はAIでも書ける。一次情報が差別化になる。
- **不安をひとつずつ潰す**。初心者の「わからない・怖い」を先回りして言語化して解消する。

---

## 1. 記事の黄金テンプレート（この順番で書く）
1. **リード文**：悩み提示 → 結論先出し → 自分の実績/経験で信頼 → この記事で分かること
2. **結論（要点）**：先に答え。「迷ったらこれ」を明示
3. **本論**：手順型（①②③）or PREP（結論→理由→具体例→再結論）で2〜5ブロック
4. **メリット・デメリット両方**：デメリットも正直に書く（信頼の核）
5. **注意点・失敗例**：自分の失敗談を入れる
6. **FAQ（よくある質問）**：残った疑問を3〜5個Q&Aで
7. **まとめ**：要点再確認 → 次の行動（CTA／次に読む記事）

---

## 2. リード文のルール（最重要・ここで離脱が決まる）
- [ ] 冒頭で**読者の悩みを箇条書き**で3つ前後（「〜って思っていませんか？」）
- [ ] すぐに**結論・安心**を提示（「結論、未経験でも◯◯すれば大丈夫です」）
- [ ] **自分の立場・実績を一言**（「未経験から副業を始め、AIで制作している私が解説します」）
- [ ] 「この記事を読むと何が分かるか」を提示
- [ ] 長くしない（5〜8行程度）。専門用語は使わない

---

## 3. 見出し構成のルール
- [ ] H2だけ読んで記事の流れ・結論が分かるようにする（見出しは説明的に）
- [ ] 手順記事は「**手順①〜**」で操作順に完全準拠（迷わせない）
- [ ] 比較記事は「**結論3択 → 各詳細 → 選び方の基準 → 比較表 → FAQ**」の順
- [ ] H2に数字を入れる（「3つの手順」「初心者が選ぶべき2つ」）
- [ ] 1見出し1メッセージ。長くなったらH3で分割

---

## 4. E-E-A-T（自分の強みの出し方）
信頼は「実績数字 × 実体験 × 正直さ」で作る。自分の場合の見せ方：
- [ ] **経験(Experience)**：「実際にやってみた」「私も最初は◯◯でつまずいた」を必ず入れる
- [ ] **具体的な数字・期間**：「◯ヶ月で」「◯円かかった」「◯時間で出来た」
- [ ] **正直なデメリット**：良い面だけでなく、向かない人・注意点を書く（売り込み感が消える）
- [ ] **一次情報の証拠**：自分で撮ったスクショ、実際の画面、結果。可能ならSNS実績の埋め込み
- [ ] **運営者情報**：プロフィール（未経験スタート／低スペPC／YouTube・AI制作・ブログ）への導線
- [ ] 統計・公式情報を引用するときは出典を明記

---

## 5. 文体・トーンのルール
- [ ] 一人称は「**私**」で統一、語りかけ調（「〜ですよね」「一緒に進めましょう」）
- [ ] **読者の心情を代弁**（「ここで手が止まりますよね」「えっ難しそう…と思ったはず」）
- [ ] 「**私も最初はそうでした**」と共感ベースで寄り添う
- [ ] 1文を短く。3〜4文ごとに改行。読みやすさ優先
- [ ] 言い切る（「〜だと思います」より「〜です」）。ただし条件付けは柔軟に（「ただし◯◯な人は別」）
- [ ] 煽りすぎ・誇大表現はNG（「絶対稼げる」等は使わない）

---

## 6. CTA（アフィリエイト誘導）のルール
3ブログ共通の「押し売りに見せない多層CTA」を真似る。
- [ ] CTAは**学習ステップが完了した直後**に置く（行動できる気持ちになった瞬間）
- [ ] 1記事に**2〜4箇所**。商品の直後／まとめ前／関連記事末
- [ ] **確認型の言い回し**で売り込み感を消す（「公式サイトで確認する」「気になる方はこちら」）
- [ ] **無料・限定・割引**を訴求（「無料登録」「期間限定◯%OFF」）※事実のみ
- [ ] リンク前に**自然につなぐ一文**（「◯◯で迷うなら、まず△△を試すのがおすすめです」）
- [ ] アフィリを含む記事は**PR表記**を入れる
- [ ] 差し込み位置の目印 `<!-- ▼アフィリエイト：ここに貼る▼ -->` を使い、後でアプリの🔗から挿入

---

## 7. 内部リンクのルール
- [ ] 記事は**ピラミッド構造**で繋ぐ：入口記事（概論）→ 実装記事（手順）→ 運用記事（コツ）
- [ ] 本文中に**文脈に沿って3〜5個**「詳しくは△△で解説しています」
- [ ] 記事末に「**あわせて読みたい**」で関連3〜6記事をカード表示
- [ ] 「このステップが終わったら次は◯◯へ」と**次の行動**を必ず示す
- [ ] 関連の薄いリンクは貼らない（テーマの一貫性を保つ）

---

## 8. 視覚要素のルール
- [ ] **吹き出し**で会話・補足（読者の疑問役／自分の解説役）※Cocoonの吹き出し機能を活用
- [ ] **スクショ・画像**を多用（手順は1ステップ1枚が理想）。altに説明を入れる
- [ ] **比較表**：列に「価格／おすすめ度(★)／初心者向け(◎○△)／こんな人におすすめ」
- [ ] **箇条書き**で情報を整理しスキャンしやすく
- [ ] **注釈ボックス**（メモ／注意／ポイント）で情報に階層をつける
- [ ] 重要な**数字・結論を太字**でハイライト（太字は乱用しない）

---

## 9. 自分だけの独自性を出すルール（差別化＝最大の武器）
企業や大手ブロガーが書けない「リアルな一次情報」で勝つ。意識的に入れる：
- [ ] **「低スペック・旧型PCでもできた」**視点（高い機材は要らない安心感）
- [ ] **「AI（Claude等）を実際に使った制作プロセス」**の具体公開（プロンプト例・ビフォーアフター）
- [ ] **未経験スタートのリアルな数字・つまずき・解決**（きれいごとにしない）
- [ ] **複数メディア運営（YouTube雑学・恋愛／AI制作／ブログ）**の横断的な学び
- [ ] 「今まさにやっている人」の同時進行レポート感（成功者の昔話ではなく現在進行形）

---

## 10. 投稿前チェックリスト
- [ ] リードで結論と「読むメリット」を先に言えているか
- [ ] H2だけ読んで内容が分かるか
- [ ] 実体験・自分の数字が1つ以上入っているか
- [ ] デメリット・注意点も正直に書いたか
- [ ] CTAは行動できるタイミングに、押し売りなく置けているか
- [ ] 内部リンクで「次の行動」を示したか
- [ ] タイトルと中身が一致しているか（煽りすぎていないか）
- [ ] PR表記（アフィリ記事の場合）／誤字脱字チェック
