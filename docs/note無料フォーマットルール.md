# note無料（nf_xxx）作成ルール（毎回これを適用）

note無料の下書きを**新規作成・更新するときは必ずこの形式にする**。noteはマークダウン非対応・文字色不可なので、「貼ればそのまま読める本文」＋「その記事専用の編集メモ（どこを・どうする）」の2部構成にする。

## 1. 本文（note貼り付け用フォーマット）
- **先頭のタイトルH1（# …）は入れない**（noteはタイトル欄が別）
- **見出しは「■ 」で書く**（マークダウンの `##`/`###` は使わない。noteでは記号が残るだけ）
- **`**太字**`・`` `コード` ``などのマークダウン記号は使わない**（文字だけ）
- **箇条書きは「・」／番号は「1.」**（貼ればそのまま読める）
- **引用記号 `>` は使わない**（文で表現）
- **リンクは `[文字](URL)` にしない → 「文字 URL」やベタURL**（note ではベタURLが自動でクリック可）
- **末尾にブログ送客リンク**（`https://workstartedge.com/?p=実ID` をベタ書き）
- **共存ルール厳守**：ブログ本文をコピペしない（near-verbatimも書き直す）／一人称は「私」／性別が分かる表現を使わない／データ表・アフィリは載せない
- 「次回は〜書く予定」など**内容未定の予告は書かない**

## 2. 末尾に「その記事専用の編集メモ」を付ける
本文の下に、必ずこの区切りとメモを付ける（noteには貼らない部分）：

```
═══════ この記事のnote編集メモ（どこを・どうする／この区切りより下は貼らない）═══════
①【大見出し】次の行を選択→「T」→「大見出し」（■は消す）：
　・「(本文の■見出しを実際に全部列挙)」
②【太字】次の文を選択→「B」：
　・「(本文から数字・結論・ポイントを含む文を1〜3個、実際に抜粋)」
③【画像】次の場所に挿入（行頭「＋」→画像・Geminiで作成）：
　・導入（最初の段落）のすぐ下
　・見出し「(実際の見出し名)」の下  ほか
④【サムネ】タイトルのすぐ上の画像マークから1枚（1280×670・Geminiで作成）
⑤【目次】右上「公開設定」→「目次設定」にチェック（①の見出しから自動生成）
⑥【ハッシュタグ】公開設定のタグ欄に入力 → #(元記事のkeywords/カテゴリから4〜6個)
※本文・改行・「・」・URLは貼るだけで反映／文字色は変更不可（差し色は絵文字・引用・画像で）
```

**ポイント**：メモは「一般的な使い方」ではなく、**その記事の実際の見出し行・実際の文・実際の場所を名指し**する（汎用説明はNG）。

## 3. 実装メモ（作り方）
- 生成は `tools/_gen_notes_*.py`（元記事から本文生成）→ その後、上記の整形（■見出し化・記号除去・送客リンク・編集メモ付与）を適用する。
- 一括整形の参考ロジック：本文を `to_note()`（##→■・`**`除去・`[t](u)`→`t u`）、`■`行を抽出して①、数字/結論語を含む文を抽出して②、`■`見出しで③、keywordsから⑥を生成。
- 保存先：公開リポ `notes/nf_xxx.json`（`body` にすべて入れる）。
- CLIで記事を公開したら、[[blog-posts-system]]の公開チェックリスト通り、対応するnf無料もこの形式で作る。
