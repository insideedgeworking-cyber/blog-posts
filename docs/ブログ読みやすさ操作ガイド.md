# ブログを読みやすくする操作ガイド（場所＋操作方法）

対象：WordPress（テーマ Cocoon）／ workstartedge.com
運用前提：記事はアプリでマークダウン執筆 → `post_to_wp.py` で公開。
「どこで・どうやるか」を全部まとめています。まず【A】を一度やれば、あとは【B】を書くだけで大半が整います。

---

## 【A】一度だけやる（サイト全体の設定）

### A-1. 追加CSSを貼る（いちばん効く・最優先）
- **場所**：WordPress管理画面 → 「外観」 → 「カスタマイズ」 → 「追加CSS」
- **操作**：`docs/site-custom.css` の中身を**全部コピー → 追加CSS欄に貼り付け → 上の「公開」ボタン → サイトを Ctrl+F5**
- **効果**：本文の文字サイズ(17px)・行間(1.9)・余白・見出しデザイン・箇条書きの間隔・太字マーカー・リンク下線・表のスマホ横スクロール…が一括で読みやすくなる
- **注意**：更新するときは「追加CSSを全消し → 新しい内容を貼る → 公開 → Ctrl+F5」。“公開ボタン押し忘れ”が一番の詰まり所

### A-2. 目次を自動表示にする
- **場所**：「Cocoon設定」 → 「目次」タブ
- **操作**：「目次を表示する」にチェック → 表示位置（本文の最初の見出し前が定番）→ 保存
- **効果**：記事内の見出し（##/###）から**目次が自動生成**され、長い記事でも迷わない

### A-3. 吹き出しキャラを登録（吹き出しを使うなら）
- **場所**：「Cocoon設定」 → 「吹き出し」タブ
- **操作**：アイコン画像＋名前を登録（例：自分＝「エッジ」）→ 保存
- **効果**：あとで記事に「吹き出しブロック」を挿せるようになる（会話形式で親しみUP）

---

## 【B】記事を書くとき（アプリの本文＝マークダウンでやる）
※ここは全部「書くだけ」で反映されます。追加操作は不要。

- **見出しで章分け**：`## 大見出し`（章）／`### 小見出し`（小分け）。**3〜4段落ごとに見出し**を入れる
- **段落を短く**：1段落 2〜3文で改行。長い文は分ける（スマホで読まれる前提）
- **箇条書き**：要点は `- 項目`、手順は `1. 手順`
- **太字**：`**ここが重要**`。ただし**1画面に1〜2個まで**（多いと逆に読みにくい）
- **引用/補足**：`> 補足や注意`（薄い枠で目立つ）
- **内部リンク**：関連記事へ `[表示文字](https://workstartedge.com/?p=ID)`
- **FAQ**：末尾に `## よくある質問` を置き、Q&Aを箇条書き
- **リード文**：最初の2〜3行で「誰の・何の記事か」と結論を提示（離脱を防ぐ）

---

## 【C】画像を入れる（読み疲れ防止・Geminiで作成）

- **アイキャッチ（記事の顔）**
  - **場所/操作**：`images/cover-postXXX.png` を用意すると `post_to_wp.py` が**自動でアイキャッチ設定**（`make_cover.py` でも作れる／Geminiで作ってもOK）
- **本文中の図解・イメージ画像**
  - **操作**：本文（マークダウン）に `![説明](画像URL)` で挿入。`post_to_wp.py` が画像をWPへ自動アップ＆URL差し替え
  - **コツ**：見出しごと・区切りごとに1枚あると読み疲れしない。図解・比較イメージが特に効く（Geminiの画像生成で作成）

---

## 【D】公開後にさらに凝る（任意・WPの記事編集画面で手動）
※これらは Cocoon独自ブロックで、マークダウン（post_to_wp）では入りません。凝りたい記事だけ、公開後にWP編集画面で足します。

- **ボックス（情報/注意/ポイントを枠で囲む）**
  - **場所/操作**：記事編集画面 → ブロック追加「＋」 → 「Cocoonブロック」→「ボックス（アイコンボックス等）」→ 中に文章
- **吹き出し（会話形式）**
  - **場所/操作**：「＋」→「Cocoonブロック」→「吹き出し」→ 登録キャラを選ぶ（A-3で登録が必要）
- **ボタン（CTA・リンク誘導）**
  - **場所/操作**：「＋」→「Cocoonブロック」→「ボタン」→ リンク先URLを設定
- **マーカー（蛍光ペン風）**
  - **場所/操作**：文字を選択 → ツールバーの「マーカー」アイコン
- **表**
  - マークダウンの表は post_to_wp 非対応。表を使うならWP編集画面の「テーブル」ブロックで作る（CSSでスマホ横スクロール対応済み）

---

## 優先順位（迷ったらこの順で）
1. **【A-1】追加CSSを貼る**（一度で全記事が読みやすく・最重要）
2. **【A-2】目次ON**
3. **【B】書き方**（見出し・短い段落・箇条書き・太字ひかえめ）を習慣に
4. **【C】画像**（アイキャッチ＋本文に図解／Gemini）
5. 余裕があれば **【D】ボックス・吹き出し**で凝る（凝る記事だけ）
