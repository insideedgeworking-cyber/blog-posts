# 記事作成ガイド

> このファイルは、アプリで本文を生成・修正するときに**自動で読み込まれ、AIへの指示に反映される**。
> ここを書き換えれば、コードを触らずに記事の方針を調整できる。気づいた修正点はどんどん「修正メモ」に追記すること。

---

## 1. 文章の基本方針

- **読者像**：そのテーマを検索する初心者〜中級者。専門用語はかみ砕いて説明する。
- **トーン**：丁寧だが堅すぎない。押し売り・過度な煽りはしない。信頼できる先輩が教えるイメージ。
- **一人称の経験を入れる**：「実際にやってみると」「試した結果」など、体験ベースの一次情報を必ず入れる（後述のExperienceがSEOで最重要）。
- **結論ファースト**：各見出しの冒頭で結論→理由→具体例の順。
- **文章のリズム**：1文を短く。3〜4文ごとに改行。箇条書き・表を活用して読みやすく。

### 記事の基本構成テンプレート
1. **導入（リード文）**：読者の悩みに共感 → この記事で何が分かるかを提示（200字前後）
2. **結論/要点**：先に答えを示す
3. **本論**：`##` 見出しで2〜5ブロック。各ブロックに具体例・手順・数字
4. **注意点・失敗例**：体験ベースで
5. **まとめ**：要点の再確認 → 次の行動（CTA）

## 3. SEO対策（2026年版・詳細）

検索環境の前提：AIによる記事の大量生成が一般化したため、Googleは「**実体験に基づく一次情報**」と「**信頼性**」をこれまで以上に重視している。テクニックより**読者の悩みを本当に解決する記事**が勝つ。

### 3-1. E-E-A-T（最重要・記事の土台）
Googleの品質評価の4要素。特に **Experience（経験）** と **Trust（信頼）** が重要。

- **Experience（経験）**：実際に使った・試した・行ったことを具体的に書く。写真・手順・失敗談・正直なデメリット。AIだけで書いた一般論は順位が下がる。
- **Expertise（専門性）**：1記事で1テーマを深く掘る。浅く広くはNG。
- **Authoritativeness（権威性）**：同じテーマの記事を増やし、その分野に詳しいサイトだと認識させる（トピッククラスター）。
- **Trust（信頼性）**：著者情報・運営者情報・根拠の提示・情報の正確さ。一番重要。

### 3-2. Helpful Content（人間優先のコンテンツ）— Google公式チェックリスト
- [ ] オリジナルの情報・分析・一次情報があるか（他記事のまとめ直しになっていないか）
- [ ] テーマを十分に網羅し、読者が読後に満足し目的を達成できるか
- [ ] 見出しは内容を正確に表す説明的なもの（煽りタイトルにしない）
- [ ] 競合の検索結果より価値があるか
- [ ] 誤字・事実誤りがなく、プロの品質か
- [ ] 検索エンジンのためでなく「読者のため」に書いているか
- ❌ 避ける：検索流入だけ狙った量産、AI丸投げの大量生成、競合の要約だけ、専門外のトレンド狙い、文字数稼ぎ、公開日の偽装

### 3-3. キーワード設計
- **検索意図**を最優先（読者は何を知りたい？ 何を解決したい？）。
- メインキーワード1つ＋関連キーワード（共起語）を自然に配置。
- タイトル・最初の見出し（H2）・導入文にメインキーワードを入れる。
- キーワードの詰め込み（連呼）は逆効果。あくまで自然に。
- **単一キーワードでなくトピック全体**を網羅する（2026年の潮流）。

### 3-4. 記事構成・オンページ
- **タイトル（32字前後）**：メインKW＋ベネフィット＋具体性（数字・年・「初心者向け」など）。クリックしたくなるが内容に正直に。
- **見出し階層**：`##`→`###` を正しく。見出しだけ読んで内容が分かる構成に。
- **導入文**：結論と「読むメリット」を先に。
- **内部リンク**：関連記事へ自然にリンクし、サイト内のトピック網羅性を示す。
- **画像**：alt属性に説明を入れる。一次情報の画像（自分で撮ったもの）が強い。
- **読みやすさ**：箇条書き・表・太字（**重要語のみ**）でスキャンしやすく。
- **文字数**：目安はあるが、文字数稼ぎはNG。検索意図を満たす十分な量があればよい（多くは2000〜4000字程度）。

### 3-5. AI検索（AI Overviews / 生成AI検索）への対応
- 質問に対し**結論を簡潔に先出し**すると、AIの要約に引用されやすい。
- 「〜とは」の定義、手順、比較表など、**構造化された分かりやすい記述**が引用されやすい。
- FAQ形式（よくある質問）を入れると質問ベースの検索に強い。
- 構造化データ（FAQPageなど）の活用も有効。

### 3-6. アフィリエイト記事ならではの注意（信頼性・規約）
- **PR表記**：広告・アフィリエイトリンクを含む場合は「PR」「広告」を明記（ステマ規制対応・法律）。
- **正直なレビュー**：メリットだけでなくデメリット・向かない人も書く（誠実さが信頼＝順位につながる）。
- **比較記事**：比較表＋根拠。ランキングの理由を明示。
- **YMYL（お金・健康など）**：特に正確さ・出典・専門性が厳しく見られる。断定や誇大表現を避け、根拠を示す。
- 過度な「稼げる」訴求や誇大広告は規約違反・信頼低下のもと。

### 3-7. やってはいけないこと（ペナルティ・順位低下の原因）
- キーワードの過剰な詰め込み
- 中身のない量産記事・コピペ/リライトだけの記事
- スパム的な被リンク購入・リンクファーム
- 体験のない一般論だけのAI生成丸出し記事
- 煽りタイトルと中身の不一致（クリックされても離脱されると逆効果）
