# noteを読みやすくする操作ガイド（場所＋操作方法）

前提：noteはマークダウン非対応。本文・改行・URLは**貼ればそのまま反映**、下記の装飾だけ**note画面での操作が必要**。
（各note下書きの末尾メモにも要点あり。これは全機能の保存版）

---

## 【1】文字を「選択」すると出るツールバーでやること
まず**装飾したい文字をドラッグで選択**（反転）。すると小さいツールバーが出ます。空行では出ないので必ず文字を選択。

- **見出し**：選択 → **「T」** → 「大見出し」（章）／「小見出し」（小分け）
  - ※「見出し」という名前のボタンは無い。目印は **T**
- **太字**：選択 → **「B」**（1画面に1〜2か所まで）
- **取り消し線**：選択 → 取り消し線アイコン
- **引用（薄グレー背景で目立つ）**：選択 → **「"」（引用）**
- **リンクを文字に埋め込む**：選択 → **リンク（鎖）アイコン** → URLを入力
  - ※ただのURL（https://…）は貼るだけで自動リンク。文字にリンクを付けたい時だけこれ
- **中央寄せ／右寄せ**：選択 → 配置アイコン（見出しや一言を目立たせたい時に）

---

## 【2】行頭の「＋」からやること（ブロックの挿入）
空の行にカーソルを置くと左に **「＋」** が出ます。クリックして選ぶ。

- **画像**：＋ → 画像 → アップロード（本文中の図解に。Geminiで作成した画像でOK）
- **埋め込み（YouTube・X・リンクカード）**：＋ → 埋め込み。または**URLを単独の行に貼る**とサムネ付きカードになる
- **区切り線**：＋ → 区切り線（話題の切れ目に）
- **箇条書き／番号リスト**：＋ → リスト。※「・」や「1.」を書いて貼るだけでも読めます

---

## 【3】公開前の設定（右上「公開設定」で）
記事を書き終えて右上の **「公開設定」** を押した画面でやること。

- **目次**：「**目次設定**」にチェック → 記事内の見出し（大/小）から**自動で目次**が作られる（長い記事は必ずON）
- **ハッシュタグ**：「ハッシュタグ」欄に入力してEnter（本文には入れない）
- **見出し画像（サムネ）**：タイトルのすぐ上の**画像マーク**から設定（推奨 横1280×縦670・16:9／Geminiで作成）

---

## 【4】noteでは「できないこと」
- **文字色の変更**：不可。差し色を出したい時は **絵文字／引用の薄グレー／文字入り画像（Geminiで作成）** で代用

---

## 【5】貼るだけで効く「見せ方のコツ」（操作不要）
- **最初の2〜3行で結論・誰の何の話か**を提示（ここで読む/離脱が決まる）
- **一文は短く・改行多め**（スマホで読まれる）
- **見出しで3〜4段落ごとに区切る**（＋目次ON）
- **要点は箇条書き**、**太字は絞る**
- **最後はブログへの一言＋リンク**で締める（送客）

---

## 迷ったらこの順で
1. **見出し（T→大見出し）** を付ける ＋ **公開設定で目次ON**
2. **サムネ画像**を1枚（Gemini）
3. **太字・引用**を数か所だけ
4. **ハッシュタグ**を公開設定で
5. 余裕があれば**画像で図解／区切り線**
